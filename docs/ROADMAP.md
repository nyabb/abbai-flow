# Abbai Flow Roadmap

Abbai Flow is a self-hosted family organizer. The app server stores household
data and mediates optional service connections; no smart-home platform is
required.

## Product improvements

- Improve offline behavior and installability for shared tablets.
- Continue improving accessibility, keyboard use, and touch targets.
- Make calendar and list refresh behavior clearer on mobile.
- Refine photo library uploads, progress, and failure recovery.
- Improve backup and restore guidance for server data.
- Continue localization and translation coverage.

## Integrations

- Improve setup and error feedback for supported CalDAV, ICS, and Google
  calendar sources.
- Continue work on iCloud Reminders reliability and sync visibility.
- Expand meal planning and supported recipe data formats.
- Improve Spotify browser playback setup and connection feedback.

## Distribution

- Improve the installable web app experience.
- Document reverse proxy, kiosk, and backup setups.
- Keep Docker images current for supported server architectures.
