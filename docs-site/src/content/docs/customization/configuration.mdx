# Configuration

Configure optional calendar, reminder, weather, music, and meal services in
**Settings → Integrations**. Family and display preferences are in their
respective Settings sections. The server stores service credentials in the
persistent data directory and does not return secret values to the browser.

## Docker Compose

```yaml
services:
  abbai-flow:
    image: ghcr.io/nyabb/abbai-flow:latest
    ports: ['3000:3000']
    volumes:
      - abbai-flow-data:/data

volumes:
  abbai-flow-data:
```

Keep `/data` mounted across container restarts. It contains family data,
integration settings, and uploaded screen saver photos.

## Server environment variables

| Variable | Purpose | Default |
| --- | --- | --- |
| `ABBAI_FLOW_PORT` or `PORT` | HTTP server port | `3000` |
| `ABBAI_FLOW_DATA` | Persistent data directory | `/data` |
| `ABBAI_FLOW_DIST` | Built frontend directory | `/app/dist` |
| `ABBAI_FLOW_ALLOWED_ORIGINS` | Extra allowed origins for state-changing requests | unset |
| `ABBAI_FLOW_BLUETOOTH_DBUS_ADDRESS` | Host D-Bus address for optional Bluetooth control | unset |

## Runtime configuration

The server serves `/runtime-config.js` with safe deployment defaults. Never put
integration credentials in this file. The public copy is an empty development
stub.
