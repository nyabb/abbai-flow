# Calendar

The Calendar view combines local events, configured calendar sources, and
household chores. Use the weekly view to browse events, create or edit entries,
and drag events to a new time.

## Add calendar sources

Open **Settings → Integrations** and add a CalDAV account, ICS feed, or Google
calendar source. Local calendar events are available without connecting a
service. You can set a name and color for each source.

## Event editing

Select a time slot to create an event. Open an event to edit or delete it.
Recurring events can repeat daily, weekly, or monthly where the calendar
provider supports those operations.

## Family views

Filter the calendar by member and calendar source. Chores can appear on the
calendar under their assigned family members.
