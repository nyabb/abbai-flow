# Grocery and Tasks Lists

Abbai Flow connects directly to Apple iCloud Reminders. In **Settings → Integrations**,
sign in with your Apple Account and complete Apple's verification step. The
password is stored on the Abbai Flow server and is not sent to the browser.

## Choose lists in Abbai Flow

After iCloud is connected, choose which Reminders lists should appear in
**Grocery** and **Tasks**, then select a default grocery list. Each list can be
assigned to one of those views.

If iCloud Reminders is unavailable, Abbai Flow can use its built-in local lists.
Local list changes stay in that Abbai Flow browser and do not sync to Apple
Reminders.

## Use the lists

Open **Lists** from the navigation. The Grocery tab shows selected shopping
lists; the Tasks tab shows selected task lists. Choose a list from the selector,
add reminders, mark them complete, or edit their title, notes, due date, priority,
flag, and all-day setting. Lists with sections let you move reminders between
sections or leave them unsectioned. Deleting a reminder removes it from the
active list.

The list panel refreshes periodically while open. If a list is missing, reload
the iCloud list catalog in **Settings → Integrations** and check that the list
is selected for the appropriate view.
