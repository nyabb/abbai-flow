# Meal Plan Data

Meal plan records remain available through the existing data store and MCP tools. The dashboard Menu card has been removed, while meal integrations and stored records remain available.

Each meal is one row, sorted breakfast → lunch → dinner → snack:

| Meal      | Icon |
| --------- | ---- |
| Breakfast | 🌅   |
| Lunch     | ☀️   |
| Dinner    | 🌙   |
| Snack     | 🍎   |

---

## Where the data comes from

Meal plans are written by a sync or MCP tool. AnyList output can be converted
with `scripts/sync-meals.ts`; Grocy can provide data through
`sensor.grocy_meal_plan`. The dashboard Menu card has been removed; the meal
data and its integrations remain available.

### AnyList

`scripts/sync-meals.mjs` turns AnyList meal-plan output into the array Abbai Flow expects:

```bash
# raw MCP tool-result file, or plain text with lines like:
# - **2026-11-07** [📖] Pasta pesto [Dinner] — id: abc123
node scripts/sync-meals.mjs meal-data.txt > meal-plans.json

# limit the range
node scripts/sync-meals.mjs meal-data.txt --from 2026-11-07 --to 2026-11-21 > meal-plans.json
```

### Grocy

If you run Grocy with a meal plan, today's meals can come from `sensor.grocy_meal_plan` —
see [Grocery](/docs/features/grocery/) for the sensor setup.

---

## Storage and refresh

- Entries live under `beacon_meal_plans` in Abbai Flow's data store: server-side in Docker
  deployments, in browser storage for browser-only runs.
- Each entry looks like
  `{ "date": "2026-11-07", "meal_type": "Dinner", "name": "Pasta pesto", "recipe_id": "abc123" }`.
- `meal_type` is one of `Breakfast`, `Lunch`, `Dinner` or `Snack`; `recipe_id` is optional.
- Entries can be queried by date through `beacon_get_meal_plan`.

## Troubleshooting

### A meal plan is missing from the MCP response

Check that the sync wrote entries for the requested `YYYY-MM-DD` date and that the server's data store is available.

### Meals show the wrong day

Dates are compared as plain `YYYY-MM-DD` strings in the device's local day, so a sync that
writes UTC timestamps can land on the neighbouring day. Write the date you want displayed.

### A meal is in the wrong position

Ordering comes from `meal_type`, not from the plan's own order — anything other than the
four known types sorts last.
