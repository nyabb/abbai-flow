# Screen Saver

Enable the screen saver in **Settings → Display**. Choose **Clock only**,
**Photos only**, or **Clock and pictures**. Adjust the idle timeout, dimming,
photo interval, and transition style in Settings.

Uploaded screen saver photos are resized and saved on the app server. Keep the
`/data` volume mounted to preserve them across updates.
