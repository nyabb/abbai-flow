# Music

The Music page supports Spotify catalog and playlist features, with playback
through Encore or the current browser.

## Connect services

Configure supported music connections in **Settings → Integrations**. Spotify
playlist management and browser playback also require connecting a Spotify
account from the Music page after configuring the developer app credentials
and redirect URI. Browser playback requires Spotify Premium and plays through
the audio output selected by the computer running the browser. Reconnect
Spotify to grant browser playback permissions if the account was previously
connected only for playlists.

Register the exact HTTPS callback URL configured under **Settings →
Integrations** in the Spotify Developer Dashboard. For local development, use
an explicit loopback address such as `http://127.0.0.1` rather than `localhost`.
