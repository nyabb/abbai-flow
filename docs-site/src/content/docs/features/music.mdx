# Music

The Music page searches Spotify, manages playlists, and plays audio directly in
the current browser.

## Connect services

Configure Spotify developer app credentials and the OAuth redirect URL in
**Settings → Integrations**, then connect your Spotify account from the Music
page. Browser playback requires Spotify Premium and plays through the audio
output selected on the device running the browser. Reconnect Spotify to grant
browser playback permissions if the account was previously connected only for
playlists.

Register the exact HTTPS callback URL configured under **Settings →
Integrations** in the Spotify Developer Dashboard. For local development, use
an explicit loopback address such as `http://127.0.0.1` rather than `localhost`.
