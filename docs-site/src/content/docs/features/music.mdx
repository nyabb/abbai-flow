# Music

The Music page supports Spotify catalog and playlist features, Encore playback,
and optional Bluetooth device management when the app server can access the
host's D-Bus socket.

## Connect services

Configure supported music connections in **Settings → Integrations**. Spotify
playlist management also requires connecting a Spotify account from the Music
page after configuring the developer app credentials and redirect URI.

## Bluetooth

On a Linux host, mount the host D-Bus socket into the container and configure
`ABBAI_FLOW_BLUETOOTH_DBUS_ADDRESS`. Bluetooth access is optional; it is not
needed for other Music page features.
