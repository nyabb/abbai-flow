# Family Members

Add family profiles from **Settings → Family**. Each profile has a name,
avatar, color, role, and optional PIN. Uploaded profile pictures can be used
instead of an avatar.

Family profiles are used to assign chores and routines, show member-specific
calendar views, track rewards, and launch a focused Kid Display.
