# Notifications

Abbai Flow can show browser notifications before upcoming timed calendar
events. Enable notifications in **Settings → Calendar** and grant the browser
permission when prompted. Notification timing can be set to 5, 10, 15, or 30
minutes. All-day events do not trigger reminders.

Notifications are sent by the browser running Abbai Flow. Keep that browser
profile available and allow notifications for the app's address.
