# Photos

Open **Settings → Photos** to upload and manage screen saver images. Select one
or more images from your device; the app prepares and saves them to its photo
library. The library supports up to 50 photos. Images are resized before upload
to reduce storage and transfer time.

The photo library is stored with the app's server data. Keep `/data` mounted to
preserve photos across container updates. Choose photos or a clock-and-photo
slideshow in **Settings → Display**.
