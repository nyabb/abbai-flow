# Getting Started

## Docker

```bash
docker run -d \
  --name abbai-flow \
  --restart unless-stopped \
  -p 3000:3000 \
  -v abbai-flow-data:/data \
  ghcr.io/nyabb/abbai-flow:latest
```

Open `http://<server-address>:3000`. Keep the `/data` volume mounted so family
records, integration settings, and screen saver photos persist across updates.
Images are available for `linux/amd64` and `linux/arm64`.

## Docker Compose

```yaml
services:
  abbai-flow:
    image: ghcr.io/nyabb/abbai-flow:latest
    restart: unless-stopped
    ports: ['3000:3000']
    volumes: ['abbai-flow-data:/data']

volumes:
  abbai-flow-data:
```

Open **Settings → Integrations** to connect the calendar, reminders, weather,
music, or meal services your household uses. Local calendars and task lists
work without external connections.

## Local development

```bash
git clone https://github.com/nyabb/abbai-flow.git
cd abbai-flow
npm ci
npm run dev
```

The Vite development server runs at `http://localhost:3000` and uses browser
storage. See [Configuration](/docs/customization/configuration/) for server
environment variables and [Deployment](/docs/getting-started/deployment/) for
reverse proxy and kiosk setup.
