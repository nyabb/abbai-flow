# Getting Started

Abbai Flow runs as a Docker container alongside Home Assistant. It can also run without Home Assistant, using local calendars and lists.

## Docker

Create a Home Assistant long-lived access token from your profile if you want to use Home Assistant calendars, media players, weather, or lists. Then start the container:

```bash
docker run -d \
  --name abbai-flow \
  --restart unless-stopped \
  -p 3000:3000 \
  -e HA_URL=http://homeassistant.local:8123 \
  -e HA_TOKEN=your_long_lived_access_token \
  -v abbai-flow-data:/data \
  ghcr.io/nyabb/abbai-flow:latest
```

Open `http://<server-address>:3000`. Images are available for `linux/amd64` and `linux/arm64`.

Without `HA_TOKEN`, Abbai Flow runs in standalone mode. Local calendars, tasks, and shopping lists remain available.

### Docker Compose

```yaml
services:
  abbai-flow:
    image: ghcr.io/nyabb/abbai-flow:latest
    restart: unless-stopped
    ports:
      - '3000:3000'
    environment:
      HA_URL: http://homeassistant.local:8123
      HA_TOKEN: ${HA_TOKEN}
    volumes:
      - abbai-flow-data:/data

volumes:
  abbai-flow-data:
```

Store `HA_TOKEN` in a `.env` file next to your Compose file instead of committing it to source control.

## Local development

```bash
git clone https://github.com/nyabb/abbai-flow.git
cd abbai-flow
npm ci
npm run dev
```

The development server runs at `http://localhost:5173`. To connect to Home Assistant, create a root `.env` file with:

```bash
VITE_HA_URL=http://homeassistant.local:8123
VITE_HA_TOKEN=your_long_lived_access_token
```

See [Configuration](/docs/customization/configuration/) for the available environment variables and [Deployment](/docs/getting-started/deployment/) for reverse proxy and kiosk setup.
