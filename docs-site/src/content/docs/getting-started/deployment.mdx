# Deployment

Abbai Flow runs in a Docker container and serves the web app on port `3000`. See [Getting Started](/docs/getting-started/installation/) for the initial Docker command and Compose file.

## Reverse proxy

Put the container behind a reverse proxy when you want to use HTTPS or a domain name. Keep the Docker port bound to your private network and use your existing TLS certificate setup.

### Nginx

```nginx
server {
    listen 443 ssl;
    server_name family.example.com;

    ssl_certificate /path/to/fullchain.pem;
    ssl_certificate_key /path/to/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### Caddy

```caddy
family.example.com {
    reverse_proxy localhost:3000
}
```

## Kiosk display

Open the deployment URL in a browser on the display. For Chromium-based kiosks, start the browser in fullscreen mode:

```bash
chromium --kiosk --noerrdialogs --disable-infobars https://family.example.com
```

Configure the device to launch this command at startup using its operating system's kiosk or autostart settings. The app includes a screen saver and touch-friendly layout for wall-mounted displays.

## Backups and updates

Persist `/data` with a Docker volume or bind mount. Back up that volume along with the browser's local storage if you use standalone local lists or calendars.

To update the container:

```bash
docker compose pull
docker compose up -d
```

To inspect logs:

```bash
docker compose logs -f abbai-flow
```

## Troubleshooting

### The container cannot connect to Home Assistant

Check that `HA_URL` is reachable from inside the container and that `HA_TOKEN` is valid. If Home Assistant uses a private certificate authority, configure the server's CA trust before connecting.

### The page does not load through the reverse proxy

Confirm the container is healthy at `http://<server-address>:3000` first, then check the proxy target and TLS configuration.

### The display does not stay awake

Disable the operating system's sleep timer or use its kiosk mode. Abbai Flow can move the screen saver clock to reduce static image retention, but it cannot override device power settings.
