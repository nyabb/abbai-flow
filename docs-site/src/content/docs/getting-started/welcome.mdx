# A better family organizer

Abbai Flow keeps family calendars, chores, rewards, meals, lists, and routines
together on a shared display, tablet, or phone. The app and household data run
on your own server.

## What you can do

- Add local events or connect CalDAV, ICS, and Google calendar sources.
- Manage chores, routines, rewards, points, and family profiles.
- Connect iCloud Reminders or use built-in task lists.
- Configure weather, music, and meal data sources from Settings.
- Upload photos for a screen saver with a clock, photos, or both.
- Use the responsive layout on a phone, tablet, or wall display.

## Get started

Follow the [installation guide](/docs/getting-started/installation/) to start
the Docker image and configure the services your household uses.
