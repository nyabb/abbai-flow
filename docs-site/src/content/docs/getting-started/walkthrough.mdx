# Visual Walkthrough

This page is a screenshot-guided tour of Abbai Flow. Every major view is shown at both desktop (1280x800) and mobile (390x844) sizes so you know exactly what to expect.

> Screenshots are from a live Abbai Flow instance running in Docker.

---

---

## Calendar

A full week view with color-coded events from connected calendar sources. Filter pills toggle calendars on or off. Inline weather shows each day's high and low. Tap any empty time slot to quick-add an event.

### Desktop

![Calendar on desktop](/docs/images/calendar-desktop.png)

### Mobile

![Calendar on mobile](/docs/images/calendar-mobile.png)

On mobile the calendar shows a scrollable 3-day view with page navigation.

---

## Chores

Assign recurring or one-off chores to family members. Each member gets a card showing their avatar and assigned tasks. Tap a chore to mark it done — completions add points to that child's pot.

### Desktop

![Chores on desktop](/docs/images/chores-desktop.png)

---

## Lists (Grocery / Shopping)

Manage grocery and task lists from iCloud Reminders. Connect your Apple Account in **Settings → Integrations** to make your lists available in Abbai Flow.

### Desktop

![Lists on desktop](/docs/images/lists-desktop.png)

### Mobile

![Lists on mobile](/docs/images/lists-mobile.png)

## Music Controls

Use connected music services to browse and play music. Optional Bluetooth device controls are available when configured on the app server.

### Desktop

![Music on desktop](/docs/images/music-desktop.png)

### Mobile

![Music on mobile](/docs/images/music-mobile.png)

## Weather

Current conditions with humidity, wind, and pressure plus a 7-day forecast. Open-Meteo is the default and backup; a custom JSON API can be mapped in **Settings → Integrations**.

### Desktop

![Weather on desktop](/docs/images/weather-desktop.png)

### Mobile

![Weather on mobile](/docs/images/weather-mobile.png)

## Settings

Configure themes, family members, calendar sources, list providers, Open-Meteo and optional custom weather APIs, and display options.

## Desktop vs. Mobile Navigation

|                  | Desktop               | Mobile                                                       |
| ---------------- | --------------------- | ------------------------------------------------------------ |
| **Layout**       | Vertical icon sidebar | Bottom tab bar + More                                        |
| **Primary tabs** | All views visible     | Calendar, Chores, Lists, Music                                |
| **Overflow**     | None needed           | More menu for Lists, Tasks, Photos, Timer, Weather, Settings |
