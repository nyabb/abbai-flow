# Contributing

Contributions are welcome. Before opening a pull request, run the relevant tests, type checks, and linting for your changes.

## Development setup

Requirements: Node.js 20 or later and npm 9 or later.

```bash
git clone https://github.com/nyabb/abbai-flow.git
cd abbai-flow
npm ci
npm run dev
```

The Vite development server runs at `http://localhost:5173`. To connect to a Home Assistant instance, create a `.env` file in the repository root:

```bash
VITE_HA_URL=http://homeassistant.local:8123
VITE_HA_TOKEN=your_long_lived_access_token
```

Run checks with:

```bash
npm test
npm run typecheck
npm run lint
```

## Project structure

```text
src/
  api/             Home Assistant and persistence clients
  components/      Views, settings, and reusable UI
  hooks/           React state and browser integration
  styles/          Base styles and theme definitions
  types/           Shared TypeScript types
server/            Docker HTTP and Home Assistant proxy
docs-site/         Astro documentation site
```

For runtime settings, see [Configuration](/docs/customization/configuration/). For Home Assistant and server interfaces, see the [API Reference](/docs/reference/api-reference/).
