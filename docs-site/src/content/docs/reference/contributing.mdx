# Contributing

Contributions are welcome. Before opening a pull request, run the relevant tests, type checks, and linting for your changes.

## Development setup

Requirements: Node.js 20 or later and npm 9 or later.

```bash
git clone https://github.com/nyabb/abbai-flow.git
cd abbai-flow
npm ci
npm run dev
```

The Vite development server runs at `http://localhost:5173`. Enter Home
Assistant credentials through onboarding or **Settings → Integrations**. Home
Assistant must allow requests from the development origin.

Run checks with:

```bash
npm test
npm run typecheck
npm run lint
```

## Project structure

```text
src/
  api/             Connected service clients and persistence
  components/      Views, settings, and reusable UI
  hooks/           React state and browser integration
  styles/          Base styles and theme definitions
  types/           Shared TypeScript types
server/            Docker HTTP server and connected service APIs
docs-site/         Astro documentation site
```

For runtime settings, see [Configuration](/docs/customization/configuration/). For server interfaces, see the [API Reference](/docs/reference/api-reference/).
