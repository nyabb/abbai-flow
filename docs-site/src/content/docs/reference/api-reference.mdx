# API Reference

The app server serves the built frontend and same-origin APIs. Request handling
and persistent storage live in `server/app.cjs`; frontend clients live under
`src/api/`.

## Persistent data

`GET /abbai-flow/data/:key` reads a JSON document from the configured data
directory. It returns `null` when the document is not present. `PUT` writes a
JSON document atomically. State-changing requests are checked by the server's
same-origin guard.

## Planner mutations

`POST /api/planner/mutate` applies a planner operation using the shared rules in
`src/api/planner-rules.ts`. The request includes a target, operation, and
idempotency key. The server returns the resulting document and whether it
changed.

## Connected services

Calendar, reminder, weather, meal, music, and optional Bluetooth APIs are
served under `/abbai-flow/`. Their frontend request wrappers and response types
are maintained in the matching files under `src/api/`.

## Runtime configuration

`GET /runtime-config.js` returns safe deployment defaults used by the browser.
It does not contain integration credentials.
