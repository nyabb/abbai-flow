# Frequently Asked Questions

## Do I need an account or subscription?

No. Abbai Flow is open source and self-hosted. You can use local calendars,
chores, and task lists without connecting an external service.

## What calendars are supported?

Abbai Flow supports local events and configured CalDAV, ICS, and Google calendar
sources. Add sources in **Settings → Integrations**.

## Can I use it on a phone?

Yes. The app has a responsive phone layout with a bottom navigation bar.

## Can I show family photos?

Yes. Upload up to 50 screen saver photos in **Settings → Photos**, then choose
clock, photos, or both in **Settings → Display**.

## Where is my data stored?

In a Docker deployment, app data is stored in `/data`. Keep that volume mounted
and back it up with your other household files.

## Can I back up my data?

Back up the Docker `/data` volume. A static development build also uses the
browser's local storage, which is specific to that browser profile.

## Does Abbai Flow send analytics?

The app does not include telemetry. When you connect an external service, the
app server sends requests to that provider to perform the requested sync or
lookup.
